`arcade-maze.png` is the transparent 224 × 288 playfield art from
[sgothel/pacman](https://github.com/sgothel/pacman/blob/master/media/playfield_pacman.png).
That project credits Superjustinbros's *Arcade - Pac-Man - General Sprites* sheet
as its source. The bitmap is used only for the blue wall pixels; dots, gate,
actors, and HUD are rendered separately.
