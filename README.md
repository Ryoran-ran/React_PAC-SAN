# PAC-SAN（パックサン）

[ブラウザでPAC-SANを遊ぶ](https://ryoran-ran.github.io/React_PAC-SAN/)

1980年アーケード版のゲームシステム再現を目指す、React / TypeScript / Vite / Canvas 2D製の迷路アクションです。**現在はPhase 3（ゲーム進行）まで実装**しています。

## 起動

Node.js 22.12以上（22系）、または20.19以上（20系）が必要です。

```sh
npm install
npm run dev
```

表示されたローカルURL（通常 `http://127.0.0.1:5173`）をブラウザーで開きます。

この作業環境では既存のNode.jsリンクが利用できなかったため、公式Node.js 22.22.1をプロジェクト内の `.tools` に配置しました。システム設定は変更していません。PowerShellでは次の方法でも起動できます。

```powershell
$env:Path = (Join-Path $PWD '.tools\node-v22.22.1-win-x64') + ';' + $env:Path
npm.cmd run dev
```

## 操作

起動時とゲームオーバー後はスタート画面でモードを選びます。アーケードとナイトメアはEnterで盤面へ進み、従来どおり盤面の「PUSH ENTER」で再度Enterを押して開始します。ナイトメアはアーケードと同じ残機・得点・面進行で、通常時の4体のゴーストだけが連携して追い詰めます。フリープレイを選ぶと専用の設定画面が開き、開始ラウンド（1〜255）、ゴースト数（0〜4体）、ゴーストAI（通常／ナイトメア）を決めて盤面へ進みます。こちらも「PUSH ENTER」で開始します。ミスしても残機を消費せず、ドット・得点を残して同じラウンドから再開します。フリープレイの得点はアーケードのハイスコアには反映されません。一時停止後に表示される「タイトルへ戻る」からモードを選び直せます。

| キー | 動作 |
| --- | --- |
| Enter | モード・設定を決定して盤面へ進み、「PUSH ENTER」でゲームを開始 |
| ↑ / ↓、W / S | スタート画面でアーケード・フリープレイ・ナイトメアを順に選択 |
| 1 / 2 / 3、N | スタート画面でアーケード／フリープレイ／ナイトメアを直接選択 |
| Tab | スタート画面の設定欄・開始ボタンへ移動。設定欄では矢印キーで値を変更 |
| ↑ ↓ ← → / W A S D | 移動。次の方向を先行入力可能 |
| P / Esc | 一時停止・再開 |
| F3 | デバッグ情報と自動操作レベルを表示 |

画面内のボタンでも操作できます。ウィンドウから離れると自動的に一時停止し、再開にはPまたは再開ボタンを使います。サウンドは♪ボタンでオン・オフできます。

F3のデバッグ欄で「自動操作」を選ぶと、プレイヤーが敵の位置を見ながらドットへ進みます。初心者は近くの敵だけを見て進み、標準・上級・TASの順に先の敵位置をより広く評価します。矢印キー・WASD・画面の方向ボタンを使うか、F3を閉じると手動操作に戻ります。TASは決定的な経路探索の実験モードで、原作の最適手順を保証するものではありません。

デバッグ表示中は、左のゲーム枠にある「表示設定」を開くと、迷路上の補助表示や右のデバッグ情報を項目ごとにオン・オフできます。設定はデバッグ表示を閉じて再度開いても維持されます。画面外にある敵の目標は、実際の座標を右のデバッグ欄に残したまま、線とマーカーを迷路の端まで表示します。

TASの調査には、F3の「記録開始」からゲーム履歴を収集し、「停止」または記録中のまま「JSON出力」を押します。JSONには60 Hzごとの自機・敵の位置、方向、モード、残りドット、スコア、乱数状態と、自動操作・敵の判断、入力、ドット・フルーツ取得、敵の捕食、死亡、面の切替などのイベントが入ります。直近10分まで保持し、超過時は古い記録を破棄して `droppedFrames` / `droppedEvents` に件数を記します。記録開始時点の残りドット配置は `initialDots` に入ります。これは解析用の履歴で、ゲームを再生する機能ではありません。

`events[].sequence` は、そのイベント直後の `frames[].sequence` に対応します。座標は盤面のピクセル単位で、`initialDots[].index` は `tileY * 28 + tileX` です。新しいゲームでは `frame` が0に戻るため、複数ゲームを通した並びには `sequence` を使います。

## AI学習ラボ

ヘッダーの「AI TRAINING LAB」から、遺伝的アルゴリズムによる自動学習画面を開けます。8〜24体を同じ条件で同時に走らせ、エサへの距離、危険回避範囲、ゴーストの先読み、パワーエサ・フルーツの優先度、反転・再訪の抑制を遺伝子として最適化します。各個体は2つの共通乱数シードで評価され、上位2体を残して選択・交叉・突然変異を繰り返します。

速度は0.5〜64倍とMAXを選べます。MAXと「1 GENERATION」はCanvas描画を止め、約12ms単位で処理を画面へ返すため、高速学習中も一時停止などの操作が可能です。現在最高・平均・歴代最高の適応度、世代推移、各個体のプレイ状況と先頭個体の遺伝子を確認できます。個体数は学習を初期化せずに変更でき、現在の世代を同じ人数で公平に評価した後、次世代から8・12・16・24体へ自動で切り替わります。1500px以上の広い画面では、8体を4列×2行、12体を6列×2行、16体を8列×2行、24体を8列×3行で配置し、どの個体数でも全個体と操作欄をスクロールなしで表示します。世代評価後の歴代最高遺伝子はlocalStorageへ自動保存され、JSONとしても出力できます。「BESTを1画面で観察」では、学習に使っていない乱数シード上で最良個体だけを整数倍率で大きく再生し、0.5〜16倍速で挙動を確認できます。観察中も個体群の学習はバックグラウンドで継続し、「学習画面へ戻る」から現在の世代へ戻れます。「ゲームへ戻る」で通常ゲームへ戻っても、通常プレイの状態は維持されます。

適応度は生存重視です。ゲームスコアに加えてドット進行を加点し、ラウンド突破に12,000点、評価終了時の残機1つにつき750点、生存中なら1,000点を加えます。ミス1回につき1,500点、ゲームオーバーに3,000点、停滞終了に1,000点を減点します。旧報酬のチェックポイントを読み込む場合は、育てた個体群と世代番号を維持したまま旧スコア・履歴を破棄し、新報酬で全個体を再評価します。

「報酬パラメータ」では、学習をバックグラウンドで続けたまま各加点・減点を編集できます。現在評価中の世代には混在させず、変更は次世代から全個体へ一括適用します。報酬の尺度が変わるため適用時に適応度履歴とBEST記録は新しく開始しますが、育てた個体群は引き継ぎます。保存した遺伝子JSONまたは遺伝子オブジェクトだけのJSONは「JSONを取込」から読み込めます。インポートした遺伝子は現在の評価を乱さず、次世代の候補としてエリートと一緒に投入されます。保留中の報酬設定とインポート遺伝子もチェックポイントへ保存されます。

学習状態は世代、個体群、歴代BEST、適応度履歴、遺伝用乱数状態をチェックポイントとしてlocalStorageへ自動保存します。「現在地を保存」で任意の時点にも保存でき、ゲーム画面への移動、ページ再読み込み、ブラウザーの再起動後は保存した個体群から自動再開します。ゲームエンジン全体の途中状態は保存せず、再開した世代を先頭から再評価するため、個体間の比較条件は崩れません。「学習を初期化」はチェックポイントを新しい第1世代で置き換えますが、別保存された歴代BEST遺伝子は残します。

## 実装済み

- 論理解像度224×288、8pxタイル、28×31の迷路。画面内に収まる整数倍で表示し、1倍でも収まらない小さな画面では全体を縮小します。
- スクロール不要の画面配置。スマートフォンでは操作欄をコンパクトにし、F3のデバッグ情報は画面上に重ねて表示します。
- 60 Hzの固定ステップと描画の分離。整数ピクセルの移動、壁判定、方向予約、即時反転、左右トンネル。
- 通常ドット240個、パワーエサ4個。通過したタイル中心で確実に取得し、10 / 50点加算、1 / 3フレームの移動停止。
- TITLE / READY / PLAYING / PAUSED / PLAYER_DYING / LEVEL_CLEAR / GAME_OVER。ミス後は残りドットと得点を保持して再開し、全ドット取得後は次の面へ進行。
- 赤・ピンク・水色・オレンジの4体。固有の追跡ターゲット、上・左・下・右の同距離優先、反対方向の除外、上方向禁止地点。
- SCATTER / CHASEの時間制御と、切替時に次のタイル境界で行う強制反転。ドット数と待機タイマーによる巣からの順次退出。
- パワーエサによる恐怖モード、青色・点滅表示、ゴースト捕食の200 / 400 / 800 / 1600点、目だけの巣への帰還。恐怖中はSCATTER / CHASEの時間を停止。
- ゴースト接触による死亡、残機3からの再開とゲームオーバー。1万点到達時に残機を1つ追加。
- スタート画面でのモード選択。フリープレイはラウンド・ゴースト数・ゴーストAIを設定でき、残機制限なしで続行。ナイトメアはアーケードのルールでゴーストだけが連携して動く。
- フリープレイでは追跡のみ／巡回のみを選べるほか、通常AIで4体それぞれの追跡方法を入れ替えられる（例：ピンキーにアカベイの追跡方法を割り当てる）。
- 盤面の右下には現在のラウンド番号を表示。取得したフルーツの履歴は右側の情報欄で確認できる。
- ドット70個・170個取得時のフルーツ、約9〜10秒の表示とレベル別得点。面ごとの速度・恐怖時間・フルーツ・巣退出条件・エルロイ段階。
- デバッグ専用の4段階オートプレイ。敵の通路距離と進行方向を使ってドットまでの経路を選びます。
- 複数個体を同時評価する遺伝的アルゴリズム学習ラボ。共通シード、エリート保存、交叉・突然変異、適応度グラフ、0.5〜64倍と描画なしMAX速度に対応。
- ハイスコアのlocalStorage保存（利用できない場合もプレイ可能）。F3による座標・モード・ターゲット・方向候補のデバッグ。

原作のフレーム単位の判定順序やスプライト、細かな巣カウンタは今後照合します。256面バグは後続Phaseの対象です。現在のオートプレイは実験的な経路探索で、全局面での生存やクリアを保証しません。
