# 原作との対応と残課題

現在の到達点はPhase 3（ゲーム進行）です。ROM単位・フレーム単位での厳密再現は宣言しません。

## 参照した資料

- ユーザー提供の [開発仕様書 v1.0.0](specification.md)。実装範囲・仕様の優先根拠です。
- Jamey Pittman, [The Pac-Man Dossier](https://pacman.holenet.info/), v1.0.27。ドット数・得点・停止フレーム・レベル別速度・恐怖時間・フルーツを参照。
- [Midwayの運営マニュアル](https://manuals.plus/m/642ab81e61008bbb53cd2f9a003ebce83a8b6f8abc26e073a4cca960c42a318c.pdf)。標準設定の開始残機とボーナス残機の得点を参照。
- Shaun Williams, [pacman / maps.js](https://github.com/masonicGIT/pacman/blob/master/src/maps.js)。原作迷路の地形・パワーエサ配置を照合するために参照。
- 同 [Actor.js](https://github.com/masonicGIT/pacman/blob/master/src/Actor.js)。レベル1通常時の互換ステップ表（1フレーム1px）を参照。エンジン・描画のソースを流用していません。

## 仕様に対応した部分

| 項目 | 実装と検証範囲 |
| --- | --- |
| 画面 | 224×288、迷路28×31、タイル8px、黒地・青い壁。表示領域に収まる整数倍で表示し、1倍未満が必要な場合のみ縮小 |
| 地形 | 壁・通路・ハウス内部・ゲート・通行不可の外側空間を分離 |
| ドット | 通常240 + パワー4、合計244・2600点。全配置が開始位置から到達可能 |
| 壁判定 | 整数座標とタイル中心による通行判定。壁描画の輪郭とは独立 |
| 入力 | 4方向、次の曲がり角まで予約、通路途中の即時反転 |
| トンネル | 迷路14行目の左右接続。プレイヤーの画像も反対側に連続描画 |
| 取得停止 | 通常1フレーム / パワー3フレーム。描画や固定更新は継続 |
| 再現性 | 同じ初期状態・入力列なら同じ状態と残存ドット集合 |
| ゴーストAI | 4体固有のターゲット、平方距離、反対方向除外、上・左・下・右の優先順位、4地点の上方向禁止 |
| モード | レベル別のSCATTER / CHASE時間列と、切替時に次のタイル中心で行う強制反転。恐怖中は時間を停止 |
| ゴーストハウス | ピンク→水色→オレンジの順序、ドット条件と停止時タイマー、専用の上下移動・退出経路 |
| 恐怖・捕食 | パワーエサで青色になり、終盤は点滅。ランダムな方向選択、捕食得点200 / 400 / 800 / 1600、目だけで巣へ帰還して復帰 |
| 死亡・残機 | 通常ゴーストと接触すると死亡演出。得点・残りドットを保持して再配置。初期3機、1万点で1機追加、残機が尽きたらゲームオーバー |
| フルーツ | 70・170ドット取得時に出現。9〜10秒表示し、レベルに応じた得点を加算 |
| 面進行 | 全244ドット取得でクリア演出後に次の面へ。速度・恐怖時間・フルーツ・巣退出条件・エルロイ段階をレベル別に変更 |
| 自動操作 | デバッグ中のみ選択できる4段階の経路探索。敵との通路距離と進行方向の予測を経路コストへ加算 |

| --- | --- | --- |

| F-02 | タイル中心を両軸とも `tile × 8 + 4` に統一。開始位置は迷路座標(112,188)。原作の軸別サブタイル位置とは未照合 | Phase 4 |
| F-03 | 曲がり角は中心で曲がる。原作のpre-turn / post-turnによる斜め補正は未実装。仕様書の4方向移動をPhase 1の基準に採用 | Phase 4 |
| F-04 | ドットを中心到達時に取得。原作のタイル進入時の取得判定・衝突順序とのフレーム照合は未実施 | Phase 4–5 |
| F-05 | 論理更新は60 Hz。レベル1は整数ステップ表で1px/frame。原作基板の厳密な垂直同期周波数とROMの移動ビット列の位相は未照合 | Phase 4–5 |
| F-06 | READYは操作確認用の90フレーム。原作の正確な開始演出時間はTODO。完成した再現値として扱わない | Phase 4 |

| F-08 | タブ非表示・ウィンドウのフォーカス喪失で一時停止するブラウザー向け動作 | ブラウザー互換対応 |
| F-09 | プレイヤーはCanvasの円弧アニメーション。原作スプライトの形状・開閉周期の厳密比較はTODO | Phase 4–5 |
| F-10 | レベル別の通常・トンネル・エルロイ・恐怖・帰還速度を割合から整数ステップに変換。原作のビット列位相や細部の速度変化は未照合 | Phase 4–5 |
| F-11 | 初期位置と散開ターゲットは現在の共通タイル中心座標へ変換。原作の軸別サブタイル位置とのフレーム照合は未実施 | Phase 4–5 |
| F-12 | レベル別の巣退出しきい値と4秒の無取得タイマーを使用。死亡後の全体カウンタ切替は簡略化しており、個別・全体カウンタの厳密条件はROM資料との照合が必要 | Phase 4 |
| F-13 | オートプレイのTAS段階は敵の直進位置を最大4タイル予測する独自の決定的な探索。原作のTASや全局面の最適解を保証しない | デバッグ拡張 |
| F-14 | 恐怖時の方向抽選は固定シードの独自PRNG。原作の擬似乱数列と方向抽選の位相は未照合 | Phase 4–5 |
| F-15 | 接触は同じ8pxタイル内で判定。原作のピクセル単位の交差・更新順序や捕食時の停止演出は未照合 | Phase 4 |
| F-16 | フルーツ表示時間は9〜10秒の決定的な抽選。原作の抽選列・出現フレームと死亡をまたぐ挙動は未照合 | Phase 4–5 |

## 後続の作業

1. Phase 4：資料を確認した上で速度テーブル・当たり判定・出現条件・アニメーションを精密化。未確認の数値は推測で埋めない。
2. Phase 5：原作録画・解析資料との比較、ゴースト経路と再現性の検証、256面バグの調査と実装。
