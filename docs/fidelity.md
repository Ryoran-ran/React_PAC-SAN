# 原作との対応と残課題

現在の到達点はPhase 2（ゴーストAI）です。通常ゲーム全体の完成や、ROM単位・フレーム単位での厳密再現は宣言しません。

## 参照した資料

- ユーザー提供の [開発仕様書 v1.0.0](specification.md)。実装範囲・仕様の優先根拠です。
- Jamey Pittman, [The Pac-Man Dossier](https://pacman.holenet.info/), v1.0.27。Gameplay Detailsのドット数・得点・停止フレーム・速度割合を参照。
- Shaun Williams, [pacman / maps.js](https://github.com/masonicGIT/pacman/blob/master/src/maps.js)。原作迷路の地形・パワーエサ配置を照合するために参照。
- 同 [Actor.js](https://github.com/masonicGIT/pacman/blob/master/src/Actor.js)。レベル1通常時の互換ステップ表（1フレーム1px）を参照。エンジン・描画のソースを流用していません。

## 仕様に対応した部分

| 項目 | 実装と検証範囲 |
| --- | --- |
| 画面 | 224×288、迷路28×31、タイル8px、黒地・青い壁。表示領域に収まる整数倍で表示し、1倍未満が必要な場合のみ縮小 |
| 地形 | 壁・通路・ハウス内部・ゲート・通行不可の外側空間を分離 |
| ドット | 通常240 + パワー4、合計244・2600点。全配置が開始位置から到達可能 |
| 壁判定 | 整数座標とタイル中心による通行判定。壁描画の輪郭とは独立 |
| 入力 | 4方向、次の曲がり角まで予約、通路途中の即時反転 |
| トンネル | 迷路14行目の左右接続。プレイヤーの画像も反対側に連続描画 |
| 取得停止 | 通常1フレーム / パワー3フレーム。描画や固定更新は継続 |
| 再現性 | 同じ初期状態・入力列なら同じ状態と残存ドット集合 |
| ゴーストAI | 4体固有のターゲット、平方距離、反対方向除外、上・左・下・右の優先順位、4地点の上方向禁止 |
| モード | レベル1のSCATTER / CHASE時間列と、切替時に次のタイル中心で行う強制反転 |
| ゴーストハウス | ピンク→水色→オレンジの順序、ドット条件と停止時タイマー、専用の上下移動・退出経路 |

## 後続の作業

1. Phase 3：恐怖・捕食・死亡・残機・フルーツ・ステージ進行。現時点では恐怖モードのないパワーエサに独自の効果を追加しない。
2. Phase 4：資料を確認した上で速度テーブル・当たり判定・出現条件・アニメーションを精密化。未確認の数値は推測で埋めない。
3. Phase 5：原作録画・解析資料との比較、ゴースト経路と再現性の検証、256面バグの調査と実装。
