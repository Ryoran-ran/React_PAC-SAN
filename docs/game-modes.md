# ゲームモード

## 実装済み

アーケードは従来のルールを維持する。ラウンド1・残機3で開始し、ミスで残機を消費する。得点はハイスコアに反映し、1万点で残機を1つ追加する。

フリープレイでは開始ラウンドを1〜255、ゴースト数を0〜4体から選ぶ。ゴースト数を減らした場合は赤・桃・水色・橙の順に残す。残機は表示・消費せず、ミス時はドットと得点を保って同じラウンドから再開する。全ドット取得後は次のラウンドへ進む。得点は記録するがアーケードのハイスコアには反映しない。どちらのモードも既存のデバッグ設定とゲーム速度設定を利用できる。

フリープレイを選ぶと専用の設定画面を開く。アーケードはモード決定後、フリープレイは設定決定後に盤面へ進む。盤面には従来どおり「PUSH ENTER」を表示し、Enterまたは開始ボタンでゲームを開始する。盤面の待機中はモード選択へ戻れる。一時停止後に現れる「タイトルへ戻る」でもモードを選び直せる。選択したモードとフリープレイ設定は新しいゲームの開始時に確定し、進行中には変更しない。ゲーム履歴には各フレームのモード、および開始イベントのモード・開始ラウンド・ゴースト数を含める。

## ナイトメア（今後の設計対象）

現時点ではスタート画面に開発予定と表示し、選択できない。アーケードのゴーストごとの原作準拠ターゲットから独立したAIとして設計する。

想定する中心要件は、4体が同じ場所へ単純に向かわず、追跡・先回り・退路封鎖・圧力維持を分担してプレイヤーを追い詰めること。通路グラフ上の到達時間、プレイヤーの選択可能な出口、パワーエサと恐怖時間、巣内・帰還中のゴーストを共同計画に含める。連携判断は再現可能な決定的処理とし、履歴へ各体の役割と狙った出口を記録できるようにする。無敵なAIを即座に作るのではなく、アーケードへの影響を遮断し、勝てる余地と難易度を実測で調整する。
