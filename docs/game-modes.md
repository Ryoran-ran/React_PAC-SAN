# ゲームモード

## 実装済み

アーケードは従来のルールを維持する。ラウンド1・残機3で開始し、ミスで残機を消費する。得点はハイスコアに反映し、1万点で残機を1つ追加する。

フリープレイでは開始ラウンドを1〜255、ゴースト数を0〜4体、ゴーストAIを通常／ナイトメア、行動を標準／追跡のみ／巡回のみから選ぶ。標準では選択したAIの従来の行動を維持する（通常AIは追跡と巡回を切り替え、ナイトメアAIは連携して追跡する）。追跡のみ・巡回のみでは切り替えずにその行動を続ける。巡回のみではナイトメアAIを選んでいても各ゴーストが巡回先を目指す。ゴースト数を減らした場合は赤・桃・水色・橙の順に残す。初期設定は通常AI・標準行動。ナイトメアAIを選んでも残機・得点・フルーツ・面進行などのフリープレイルールは変わらない。残機は表示・消費せず、ミス時はドットと得点を保って同じラウンドから再開する。全ドット取得後は次のラウンドへ進む。得点は記録するがアーケードのハイスコアには反映しない。どのモードも既存のデバッグ設定とゲーム速度設定を利用できる。

フリープレイを選ぶと専用の設定画面を開く。アーケードはモード決定後、フリープレイは設定決定後に盤面へ進む。盤面には従来どおり「PUSH ENTER」を表示し、Enterまたは開始ボタンでゲームを開始する。盤面の待機中はモード選択へ戻れる。一時停止後に現れる「タイトルへ戻る」でもモードを選び直せる。選択したモードとフリープレイ設定は新しいゲームの開始時に確定し、進行中には変更しない。ゲーム履歴には各フレームのモード、および開始イベントのモード・開始ラウンド・ゴースト数を含める。

「ゴースト別の追跡方法」を開くと、4体それぞれにアカベイ／ピンキー／アオスケ／グズタの追跡計算を割り当てられる。たとえばピンキーにアカベイを選ぶと、自機の現在位置を目標にする。これは通常AIの追跡中だけ有効で、ゴーストの見た目・巡回先・巣からの退出順・速度・恐怖状態は変わらない。ナイトメアAIは独自の連携追跡を使うため、この割り当てを参照しない。

## ナイトメア

スタート画面で単独モードとして選択でき、フリープレイ設定のゴーストAIとしても選べる。単独モードでは残機・得点・ハイスコア・フルーツ・面進行・速度・恐怖・巣の退出条件はアーケードと同じ。フリープレイではフリープレイのルールを維持する。変更するのは通常時のゴーストの進路判断だけ。

赤はプレイヤーを直接追跡し、桃は進行方向の先回り、水色は左側の出口、橙は後方から右側の退路を狙う。候補は迷路の通路グラフ上でプレイヤーから3〜8タイルの出口から選び、ゴーストの到達距離と他のゴーストが塞ぐ出口との重複を考慮する。各交差点では壁を迂回する最短通路を選ぶ。処理は決定的で、デバッグの目標表示とゲーム履歴の判断記録をそのまま利用できる。恐怖中のランダム移動と捕食後の巣への帰還は従来どおり。勝てる余地や難易度は今後プレイ履歴で調整する。
